| | |
|---|---|
| URL | `https://mcp.onion4.ai/mcp` |
| Transport | Streamable HTTP |
| Header | `Authorization: Bearer <YOUR_KEY>` (omit to work anonymously) |

## Claude Code

```sh
claude mcp add --transport http onion https://mcp.onion4.ai/mcp \
  --header "Authorization: Bearer <YOUR_KEY>"
```

`/mcp` inside Claude Code shows the connection status.

## Claude Desktop

`claude_desktop_config.json` (**Settings → Developer → Edit Config**) starts local stdio servers. A remote server with a header is connected through the [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) bridge (requires Node.js):

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "onion": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://mcp.onion4.ai/mcp",
               "--header", "Authorization:${ONION_AUTH}"],
      "env": { "ONION_AUTH": "Bearer <YOUR_KEY>" }
    }
  }
}
```

Restart Claude Desktop after saving.

## Cursor

**Settings → MCP → Add new global MCP server**:

```json title="mcp.json"
{
  "mcpServers": {
    "onion": {
      "url": "https://mcp.onion4.ai/mcp",
      "headers": { "Authorization": "Bearer <YOUR_KEY>" }
    }
  }
}
```

## Other clients

Any client with Streamable HTTP support connects with the URL and header above. Connection check from a terminal — the `initialize` call returns the server name:

```sh
curl -sS -X POST https://mcp.onion4.ai/mcp \
  -H "Authorization: Bearer <YOUR_KEY>" \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"initialize","params":{
        "protocolVersion":"2025-06-18","capabilities":{},
        "clientInfo":{"name":"curl","version":"0"}}}'
```
