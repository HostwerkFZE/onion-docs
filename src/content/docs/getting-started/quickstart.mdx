<Steps>

1. **Create an API key**

   In the [dashboard](https://user.onion4.ai/), open **API keys** and create a key. Put it in an environment variable:

   ```sh
   export ONION_API_KEY=onion_sk_...
   ```

2. **Submit a request**

   `input` is one URL and the instruction. The answer is `201 Created` with the request `id` and status `queued`. On the Free plan one submission per minute is allowed; the next one within the minute gets `429` with `Retry-After`.

   <Tabs syncKey="lang">
   <TabItem label="cURL">

   ```sh
   curl -sS -X POST https://user.onion4.ai/api/v1/parse-requests \
     -H "Authorization: Bearer $ONION_API_KEY" \
     -H "Content-Type: application/vnd.api+json" \
     -d '{"data":{"type":"parse-requests","attributes":{
           "input":"https://example.com extract the page title and the first paragraph, return the result in json"}}}'
   ```

   </TabItem>
   <TabItem label="Python">

   ```python
   import os, requests

   API = "https://user.onion4.ai/api/v1"
   HEADERS = {
       "Authorization": f"Bearer {os.environ['ONION_API_KEY']}",
       "Content-Type": "application/vnd.api+json",
   }

   r = requests.post(f"{API}/parse-requests", headers=HEADERS, json={
       "data": {"type": "parse-requests", "attributes": {
           "input": "https://example.com extract the page title and the first paragraph, return the result in json",
       }},
   })
   r.raise_for_status()
   request_id = r.json()["data"]["id"]
   ```

   </TabItem>
   <TabItem label="JavaScript">

   ```js
   // Node.js 18+, ES module
   const API = "https://user.onion4.ai/api/v1";
   const headers = {
     Authorization: `Bearer ${process.env.ONION_API_KEY}`,
     "Content-Type": "application/vnd.api+json",
   };

   const res = await fetch(`${API}/parse-requests`, {
     method: "POST",
     headers,
     body: JSON.stringify({ data: { type: "parse-requests", attributes: {
       input: "https://example.com extract the page title and the first paragraph, return the result in json",
     } } }),
   });
   if (!res.ok) throw new Error(await res.text());
   const requestId = (await res.json()).data.id;
   ```

   </TabItem>
   </Tabs>

3. **Wait for the result**

   `GET /parse-requests/{id}/result` returns `{"data": null, "meta": {"request-id": "…", "status": "queued" | "processing"}}` until the request is `ready`; then `data` is the result. A failed request has `meta.status: "failed"` and `meta.error`. Reads are not counted against the rate limit.

   <Tabs syncKey="lang">
   <TabItem label="cURL">

   ```sh
   curl -sS https://user.onion4.ai/api/v1/parse-requests/<REQUEST_ID>/result \
     -H "Authorization: Bearer $ONION_API_KEY"
   ```

   </TabItem>
   <TabItem label="Python">

   ```python
   import time

   while True:
       body = requests.get(f"{API}/parse-requests/{request_id}/result", headers=HEADERS).json()
       if body["data"] is not None:
           result = body["data"]["attributes"]
           break
       if body["meta"]["status"] == "failed":
           raise SystemExit(body["meta"].get("error"))
       time.sleep(2)
   ```

   </TabItem>
   <TabItem label="JavaScript">

   ```js
   let result;
   for (;;) {
     const body = await (await fetch(`${API}/parse-requests/${requestId}/result`, { headers })).json();
     if (body.data) { result = body.data.attributes; break; }
     if (body.meta.status === "failed") throw new Error(body.meta.error);
     await new Promise((r) => setTimeout(r, 2000));
   }
   ```

   </TabItem>
   </Tabs>

4. **Download the data**

   The result has `data-found`, `reason`, `http-status`, `final-url` and other fields, and `download-url` — a presigned link valid for 5 minutes. Request it without the `Authorization` header; for a new link, read the result again.

   <Tabs syncKey="lang">
   <TabItem label="cURL">

   ```sh
   curl -sS "<download-url>"
   ```

   </TabItem>
   <TabItem label="Python">

   ```python
   print(result["data-found"], result.get("reason"))
   print(requests.get(result["download-url"]).text)
   ```

   </TabItem>
   <TabItem label="JavaScript">

   ```js
   console.log(result["data-found"], result.reason);
   console.log(await (await fetch(result["download-url"])).text());
   ```

   </TabItem>
   </Tabs>

</Steps>
