<Steps>

1. **Key (optional)**

   Without a key the MCP server works anonymously: limits per IP address, requests not stored in an account. With a key: your plan, and requests appear in the account history with source `mcp`. Create a key in the [dashboard](https://user.onion4.ai/) under **API keys**.

2. **Add the server to the client**

   URL `https://mcp.onion4.ai/mcp`, transport Streamable HTTP. Claude Code:

   ```sh
   claude mcp add --transport http onion https://mcp.onion4.ai/mcp \
     --header "Authorization: Bearer <YOUR_KEY>"
   ```

   Claude Desktop, Cursor and other clients: [Connect a client](/mcp/clients/).

3. **Ask the agent**

   ```text
   Use Onion to extract the page title and the first paragraph from https://example.com
   ```

   The agent calls `extract_and_wait`, or `extract` and then `extract_result`. Tools: [Tools](/mcp/tools/).

</Steps>
